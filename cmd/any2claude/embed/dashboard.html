Claude Desktop only recognizes model names starting with claude-. Any2Claude intercepts requests, replaces the model name with the real model ID, and forwards them to the correct API provider. Responses stream back seamlessly.

Configure Claude Desktop

Open Claude Desktop Developer Settings, and set the Gateway URL:

Steps
1. Open Claude Desktop → Settings → Developer
2. Click Configure Third-Party Inference
3. In the Connection section, find Gateway
4. Set Gateway URL to:
http://127.0.0.1:8089 (click to copy)

Restart Claude Desktop. Your mapped models (starting with claude-) will appear in the model selector.

FAQ

Q: Will this break my normal Claude models?
A: No. Models not in the mapping table are passed through unchanged. Your original claude-opus, claude-sonnet etc. work as before.
Q: Can I use multiple API providers at the same time?
A: Yes. Each model mapping can bind to a different provider.
Q: Do I need to restart after changing settings?
A: Model and provider changes take effect immediately. Only port changes require a restart.
Q: Where is config.json stored?
A: If there's a config.json next to the exe, it uses that (portable mode). Otherwise it's at %APPDATA%\Any2Claude\config.json (Win) or ~/.config/any2claude/config.json (Linux/Mac).
